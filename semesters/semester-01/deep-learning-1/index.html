Entorno y dependencias

El repositorio del docente gestiona su entorno con uv. Según su pyproject.toml, requiere:

Paquete Versión mínima
Python ≥ 3.12
jax[cpu] ≥ 0.11.1
jupyter ≥ 1.1.1
matplotlib ≥ 3.11.2
numpy ≥ 2.5.3
pandas ≥ 3.0.6
tensorflow ≥ 2.21.0
torch ≥ 2.14.0
NoteDependencias adicionales

Los notebooks de carga de datos también importan tensorflow_datasets, torchvision y PIL (Pillow), que no aparecen en ese pyproject.toml.

Este sitio no ejecuta los notebooks de Deep Learning al construirse. El sitio no instala TensorFlow, PyTorch ni JAX, y los notebooks se ofrecen solo como enlaces a GitHub y Colab. Para ejecutarlos localmente, clona el repositorio del docente y ejecuta uv sync.

Google Colab

Cada notebook de la clase tiene un enlace Open in Colab que apunta al archivo original del docente:

https://colab.research.google.com/github/MAESTRiA-ESTADiS-CIENCIA-DATOS-Bosque/Deep_Learning_I_Fundamentos/blob/main/<ruta-del-notebook>

Colab abre solo el notebook. Los archivos de datos locales (sonnets.txt, sunspots.csv, imgs/) hay que subirlos a la sesión antes de ejecutar las celdas que los usan.
