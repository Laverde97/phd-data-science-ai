Propósito

Este dataset es un registro de vigilancia epidemiológica: pacientes atendidos en Instituciones Prestadoras de Servicios de Salud (IPS) de Medellín con diagnóstico de cáncer de mama, reportados entre 2016 y 2021. Es útil para:

  • análisis exploratorio de datos (EDA);
  • caracterización epidemiológica;
  • análisis descriptivo, temporal y geográfico agregado;
  • estudio de frecuencias por comuna, barrio, año y tipo de afiliación en salud;
  • preparación y transformación de variables;
  • aprendizaje de manejo responsable de datos de salud.

No es apto para un ejercicio estándar de clasificación supervisada de cáncer de mama. La columna evento tiene una única categoría (CANCER DE MAMA) en el 100% de los registros: no existe una variable objetivo con clases diagnósticas (p. ej. benigno vs. maligno), por lo que este dataset no debe describirse como insumo para Random Forest Classification ni Decision Tree Classification.

Diferencia frente al dataset de clasificación

Este archivo corresponde a un registro de casos de cáncer de mama (vigilancia en salud pública), no al dataset que se utilizará más adelante para distinguir clases diagnósticas mediante Árbol de Decisión o Random Forest de clasificación (por ejemplo, un dataset tipo Wisconsin Breast Cancer, con variables clínicas y una etiqueta benigno/maligno). Ambos datasets tratan el tema “cáncer de mama” pero tienen propósitos distintos: este es para análisis descriptivo/epidemiológico, el otro —pendiente de incorporar— será para clasificación supervisada.

Limitaciones para clasificación supervisada

  • evento contiene una única clase (CANCER DE MAMA) en el 100% de los 3.414 registros.
  • Un clasificador supervisado (Árbol de Decisión, Random Forest, etc.) requiere una variable objetivo con al menos dos clases con significado interpretable.
  • Por lo tanto, este dataset no es adecuado, en su forma actual, para entrenar un modelo que distinga clases diagnósticas (p. ej. benigno/maligno).
  • No se fabricará artificialmente una etiqueta a partir de otras columnas (como tipo_ss_, pac_hos_ o sexo_) para forzar un ejercicio de clasificación.
  • Para el taller de Árbol de Decisión / Random Forest de clasificación de cáncer de mama se buscará un dataset alternativo, correctamente etiquetado (ver nota de búsqueda más abajo), en una tarea separada.

Calidad de los datos

  • Dimensiones: 3.414 filas × 15 columnas.
  • Valores faltantes: 58 en total, concentrados en cod_ase_; el resto de columnas no tiene faltantes.
  • Filas duplicadas: 0.
  • Consistencia: se observa capitalización inconsistente en los valores “sin información” de comuna ("Sin informacion" vs. "SIN INFORMACION"), lo cual debería normalizarse en cualquier análisis posterior.
  • Balance de sexo_: fuertemente desbalanceado hacia F (99,5% vs. 0,5% M), consistente con la epidemiología del cáncer de mama.
  • Cobertura temporal: 6 años (2016–2021), con un mínimo de 359 registros (2016) y un máximo de 666 (2021).

Privacidad y protección de datos

WarningPrivacidad

Aunque este conjunto de datos es distribuido públicamente por su fuente oficial y su licencia permite reutilización y redistribución, contiene variables a nivel de registro que pueden funcionar como cuasi-identificadores, como edad, fechas y ubicación geográfica. Por ello, los análisis publicados en este sitio evitan reproducir filas individuales o combinaciones infrecuentes y priorizan resultados agregados. La disponibilidad pública del dataset no elimina la necesidad de un uso responsable de la información.

En particular, en este sitio:

  • no se publican ejemplos de filas individuales de pacientes;
  • no se publican fechas exactas asociadas a un caso concreto;
  • no se publican combinaciones raras (por ejemplo, barrios con un único caso) fuera del archivo de datos mismo;
  • no se afirma cumplimiento de una norma jurídica específica, ya que no se ha realizado una revisión legal formal.

Esta nota no aplica una restricción sobre el archivo cancer_de_mama.csv en sí, que se distribuye completo en este repositorio bajo los términos de su licencia oficial (ver tabla de metadatos arriba).

Acceso a los datos

El archivo completo (cancer_de_mama.csv) está disponible en esta misma carpeta del repositorio y puede descargarse directamente desde GitHub (ver sección siguiente). La fuente oficial y autoritativa del dataset es el catálogo de Datos Abiertos Colombia enlazado en la tabla de metadatos.

NoteUso didáctico

Este dataset se publica con fines didácticos y de práctica en análisis exploratorio y epidemiológico descriptivo, como parte del módulo de Machine Learning. No debe usarse para tomar decisiones individuales sobre personas ni combinarse con otras fuentes con el propósito de reidentificación.
