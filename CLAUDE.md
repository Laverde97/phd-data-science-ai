# Claude Code Instructions — PhD Data Science & AI

## Mission
Maintain this repository as a polished, reproducible doctoral learning hub and professional academic portfolio.

## Core rules
1. Keep the Quarto website elegant, minimal, responsive, and academically professional.
2. Do not invent course names, grades, instructors, research results, or academic claims.
3. Organize all course material by semester -> module -> resource type.
4. Preserve original source files whenever possible.
5. Use kebab-case English paths and Spanish user-facing labels unless explicitly requested otherwise.
6. Prefix ordered learning materials with two digits (`01-`, `02-`, ...).
7. Every `.ipynb` intended for students/readers should have an "Open in Colab" badge near the top.
8. Never commit secrets, API keys, credentials, personal data, or sensitive datasets.
9. For datasets that should not be public, commit only a README describing access and expected schema.
10. Before committing, run `quarto render` and check internal links.
